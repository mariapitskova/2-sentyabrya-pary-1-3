1.Мини-графический редактор
Программа демонстрирует основы объектно-ориентированного программирования: инкапсуляцию, наследование и полиморфизм. 
Реализованы классы геометрических фигур, которые умеют рисовать себя и вычислять площадь.

2.Архитектура проекта
- Инкапсуляция:
 В классе `Figure` координаты `_x` и `_y` скрыты. Доступ к ним только через методы `get_coords()` и `set_coords()`.
 В классе `Car` атрибут `_engine_temperature` скрыт и изменяется только через методы.
- Наследование:
  Базовый класс `Figure` наследуют `Line`, `Rect`, `Ellipse`, `Circle`, `Square`, `Triangle`.
  Все дочерние классы получают общие свойства (координаты, ширина, цвет) и расширяют их своими.
- Полиморфизм:
 Единый метод `draw()` вызывается для разных фигур в одном цикле.
 Единый метод `calculate_area()` работает для кругов и квадратов.

3. Пример использования
figures = [
    Circle(0, 0, 5),
    Square(10, 10, 4),
    Circle(2, 3, 2),
    Square(1, 1, 6),
    Circle(5, 5, 3)
]

total_area = 0
for fig in figures:
    total_area += fig.calculate_area()

print("Общая площадь:", total_area)

4. Результаты работ
  Общая площадь всех фигур: 78.53975 + 16 + 12.56636 + 36 + 28.27431 = 171.38042
